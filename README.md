# Nocturne Atlas

A 3D field guide to places that only exist when you let yourself get lost.

## Run locally

Open `index.html` in a browser with an internet connection. Three.js is loaded as an ES module from jsDelivr; display fonts are served by Google Fonts.

## Explore

- Drag the living 3D globe to turn the atlas
- Explore six destination cards and open their field notes
- Scroll through an editorial archive and a four-step wandering guide
- Keep or release a note locally in this browser
- Pause the globe; reduced-motion preferences are respected

There is no backend, tracking, audio, or account system. A saved note exists only in this browser's local storage.
